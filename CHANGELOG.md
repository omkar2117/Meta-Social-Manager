# Changelog

All notable changes to the Meta Social Manager project will be documented in this file.

## [1.0.0] - 2026-08-07

### Added
- **Single Access Token Flow**: Automatic discovery of Facebook Pages, linked Instagram Business Accounts, profile data, 30 media items, and insights.
- **Profile Summary Header**: Real-time display of profile picture, handle, bio, follower count, following count, media count, account ID, page ID, and connection status.
- **Overview Stat Cards (14 KPIs)**: Followers, Following, Posts, Reach, Total Engagement, Total Likes, Total Comments, Shares, Saves, Images, Videos, Carousels, Reels, Engagement Rate %, and Posts/Month.
- **Top Performing Content Highlight**: Cards for Most Liked Post, Most Commented Post, Top Engaged Post, and Latest Post.
- **Interactive Media Grid**: Search by caption, filter by format (Image/Video/Carousel/Reel), filter by date range, and sort by likes/comments/newest.
- **Analytics Charts**: Recharts Area & Pie charts for Reach trend, Follower growth, Engagement trend, Likes/Comments per post, and Media Type Distribution.
- **AI Recommendations Engine**: Automated analysis of engagement rate, carousel strategy, posting frequency, and short-form video optimization.
- **Report Export**: CSV exporter for profile overview, metrics, and complete post list.
- **Full Stack Express Proxy**: Express API server with CORS and static file serving for single-container deployment.
