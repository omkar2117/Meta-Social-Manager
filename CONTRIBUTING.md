# Contributing to Meta Social Manager

Thank you for considering contributing to Meta Social Manager!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/omkar2117/Meta-Social-Manager.git
   ```
3. **Create a new topic branch**:
   ```bash
   git checkout -b feature/amazing-new-feature
   ```
4. **Make your changes** and test thoroughly:
   ```bash
   npm run build
   ```
5. **Commit your changes** with descriptive messages:
   ```bash
   git commit -m "Add feature: amazing new analytics widget"
   ```
6. **Push to your fork** and submit a Pull Request.

## Code Standards
- Use TypeScript strictly; avoid using `any`.
- Maintain standard ESLint & Prettier formatting conventions.
- Never commit secrets or hardcoded tokens.
